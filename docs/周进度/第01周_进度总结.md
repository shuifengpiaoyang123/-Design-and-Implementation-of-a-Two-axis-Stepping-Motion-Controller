## 三、关键成果

### 3.1 固件架构：双节拍 + 四层分离

```
TIM2 50 kHz ──→ 脉冲发生层（相位累加器，只算"这一拍出不出脉冲"）
SysTick 1 ms ─→ 运动规划层（梯形加减速，只算"下一毫秒该走多快"）
USART1 ───────→ 协议层（解析指令 / 100 ms 状态帧）
                  ↓
               硬件抽象（方向、使能、限位、急停）
```

两层解耦的好处：**换速度曲线不用碰脉冲代码，换节拍不用碰规划代码**。圆弧插补能在一周内加进来，靠的就是这个结构——脉冲层一行没改。

**脉冲发生**用 32 位相位累加器，每拍累加 `K = v·2³² / (δ·f_tick)`，溢出即出一个脉冲。`K` 钳到 `2³¹−1` 保证每拍最多溢出一次；脉宽占 2 拍，所以上限 25 kHz。

**速度规划**用统一公式，直线、联动、圆弧共用同一个骨架：

```
v = min( v + a·T , F , √(2·a·剩余距离) )
```

第三项是"还能刹得住吗"，短行程时它先起作用，梯形自动退化成三角形，不需要单独判断。

### 3.2 两轴直线插补

按位移比例分配速度与加速度：`kx = |ΔX|/L`，`vx = F·kx`，`ax = A·kx`。两轴同一毫秒启动（`start_wait` 对齐），同一毫秒到达。

关键在于**用取整后的脉冲数反算长度**——否则末端会多走一小段斜线。

### 3.3 圆弧插补（项目二）

**方案选型：DDA，逐点比较法只做仿真对照。** 同一段 R=10 整圆、F=10 mm/s 的仿真结果：

| 指标 | DDA | 逐点比较法 |
|---|---|---|
| 进给速度波动 | **0.00%** | 41.4% |
| 半径误差 max | 6.8 µm | **3.1 µm** |
| 刀具实走行程 | 63.34 mm | 80.01 mm（多 27.3%） |
| 用时 | 6.33 s | 8.00 s（慢 26%） |

逐点比较法每步只走一个轴，45° 方向要连走两步才前进 √2 个当量，还要周期性插入纯径向修正步——这就是 41% 速度波动和 27% 额外行程的来源。而 DDA 的 `vx, vy` 是连续量，直接喂给现有的 `Stepper_SpeedToIncrement`，**脉冲层零改动**。

**实现中三个必须照做的细节**（都是仿真先暴露、再写进固件的）：

1. **切向速度用 `v = ω·R`，不能用指令 F。** 用 F 会导致起步瞬间 Y 轴跳满速；用 ω·R 还顺便把加减速融合了（`α = A/R` 折成角加速度，与直线的 `√(2as)` 同构）。
2. **速度方向取本毫秒的中点角 `θ + dθ/2`。** 用末端角会让方向永远滞后真实切线半步，轨迹持续外扩——R=10 走一圈外扩 10 µm。改中点角后降到 6.8 µm（纯量化噪声量级）。
3. **换向只在"该轴几乎不出脉冲"时允许。** 整圆在 90°/270° 需要换向，而这两点正好是正弦过零点；把约束从"只能静止换向"放宽为"速度为 0 时可换向"，加三行判断即可。

**终点收尾**：`ArcFinish` 把不足一个脉冲的残量用一次 `MoveRel` 补到位，所以整圆走完**必定**回到出发点，往返 100 次也不累积偏移。

### 3.4 上位机

PySide6 三层：`serial_link`（QThread 收数）→ `protocol`（纯解析，无 UI 依赖）→ `ui_main`（界面）。这个分层让协议解析可以脱离界面单测。

功能：串口连接、点动、定长、绝对定位、两轴联动、圆弧（半径+角度 / I,J 两种输入）、实时状态、运动曲线（F12 逐毫秒采样）、指令日志、软限位检查。

圆弧页带**实时预览**（理论弧、起点/终点/圆心标记、弧长与预计用时）和**半径误差曲线**（带 ±1 脉冲当量容差带），走完自动给出 max/mean/终点误差——这三张图可直接进报告。

## 四、实测数据

测试条件：STM32F103 + 1600 细分 + 5 mm 导程，δ = 3.125 µm，加速度 200 mm/s²。

### 4.1 定长与直线

| 项目 | 结果 |
|---|---|
| `MOV X10 F20` | 到位 10.000 mm，往返 10 次累积误差 0.000 mm |
| 1 mm 短行程 | 梯形自动退化为三角形，精确到位 |
| 加速段拟合 | a = 200.3 mm/s²（设定 200，误差 **0.15%**） |
| `LINE X10 Y10 F20` | 全程 Y−X 偏差 **0.000 mm**，两轴同帧到位 |
| `LINE X-20 Y-5 F20` | vY/vX = 0.250（理论 0.25） |
| 通信中断 4 s | 停在原地，位置变化 **0.000 mm** |

### 4.2 圆弧（10 Hz 状态帧采样）

| 指令 | 用时（理论） | 终点误差 | 半径误差 max | mean |
|---|---|---|---|---|
| `G03 X-5 Y5 I-5 J0 F5`（90°） | 1.65 s（1.60） | **0.0 µm** | 3.0 µm | 1.1 µm |
| `G03 X0 Y0 I-8 J0 F8`（整圆） | 6.34 s（6.32） | **0.0 µm** | 3.1 µm | 1.0 µm |
| `G02 X0 Y0 I-8 J0 F8`（反向整圆） | 6.40 s（6.32） | **0.0 µm** | 4.7 µm | 1.9 µm |
| `G03 X0 Y0 I-15 J0 F15` | 6.37 s（6.36） | **0.0 µm** | 3.1 µm | 1.1 µm |
| `G03 X0 Y0 I-20 J0 F20` | 6.11 s（6.38） | **0.0 µm** | 3.5 µm | 0.9 µm |
| `G03 X0 Y0 I-10 J0 F5`（慢速） | 12.31 s（12.59） | **0.0 µm** | 7.5 µm | 1.6 µm |

误差落在 **1~2.4 个脉冲当量**（3.125 µm/当量）。任务书常规精度要求 0.02 mm，余量约 **6 倍**。用时误差 < 1%，说明加减速规划正确、无累积漂移。

### 4.3 异常与边界

| 场景 | 结果 |
|---|---|
| 圆弧中发 `STOP` | 立即封脉冲，0.5 s 后位移 **0 µm** |
| 圆弧中通信超时 500 ms | 自动停车，且只停一次（不反复改目标） |
| `I/J` 同时为 0 / 缺 `I/J` / 终点不在圆上 | `ERR,2` / `ERR,1` / `ERR,2` |
| 半径 < 1 mm 或 > 200 mm | `ERR,2`（拒绝，避免 ω 发散） |
| 进给超 Vmax | `OK`，自动钳到两轴上限的较小值 |
| 上位机离线自测 | **60 / 60 项通过** |
